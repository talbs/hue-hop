    Install Hue Hop

    Skip this if it's already on your site.

    npm CDN Self-host

    In your terminal

    npm install hue-hop

    In your JavaScript

    import 'hue-hop';
import 'hue-hop/drift.css';

    In your HTML

    <script
  type="module"
  src="https://cdn.jsdelivr.net/npm/{{cdn-version}}/dist/hue-hop.js"
></script>
<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/{{cdn-version}}/dist/drift.css"
/>
