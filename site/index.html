In the Wild

Hue Hop is for short text that names something: a title, a name, a number worth noticing. Flip the side to see every one of these light and dark.

Quickstart

Three steps from npm to a colored heading. No framework, no config.

  1. 01 Install

    npm CDN 
    npm install hue-hop
     
    <script
  type="module"
  src="https://cdn.jsdelivr.net/npm/hue-hop"
></script>

    No bundler. One tag in your page, so skip step 02.

  2. 02 Import 

    import 'hue-hop';
import 'hue-hop/hues.css';

    The second line is optional. It adds the seven ready-made hues.

  3. 03 Drop One In 

    <hue-hop hue="reef">Aquemini</hue-hop>
    Result

    Aquemini
