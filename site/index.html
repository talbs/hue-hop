Hue Hop

Give each letter of a heading or name its own color, stepped from one color to another. The text stays real, so selection, find-in-page and screen readers all work. No spans, no images, no build step.

Quickstart

Two steps to a colored heading. No framework, no config.

  1. 01 Install

    npm CDN

    In your terminal

    npm install hue-hop

    In your JavaScript 

    import 'hue-hop';

    In your HTML

    <script
  type="module"
  src="https://cdn.jsdelivr.net/npm/{{cdn-version}}/dist/hue-hop.js"
></script>

    No bundler. One tag in your page.

  2. 02 Drop One In 

    <hue-hop hue="reef">Aquemini</hue-hop>
    Result

    Aquemini
