# Changelog

Newest version first. Changes go under Added, Changed, Deprecated, Removed, Fixed, or Security. Anything breaking says **Breaking** and goes at the top.

## 0.1.0 · Unreleased

### Added

- `<hue-hop>`, one custom element that colors each letter of a heading or name, stepping from a start color to an end color. The text stays text. No dependencies, under 2 KB gzipped.
- Two optional stylesheets: `hues.css` has seven ready-made color pairs, and `drift.css` slowly sways the colors back and forth on any element with `drift`.
- The site: a landing page, the docs, the Studio for making your own pair, and `llms.txt` for coding assistants.
